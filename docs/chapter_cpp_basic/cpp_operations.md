## 🔍 比较运算符——「条件裁判员」

像运动会裁判举旗判定胜负，用来比较两个值的关系：

| 运算符 | 招式名称       | 使用例          | 现实类比                 |
|--------|----------------|-----------------|--------------------------|
| `==`   | 一模一样检测术 | `5 == 3+2` ✅    | 双胞胎识别器 👯          |
| `!=`   | 找不同雷达     | `10 != 9` ✅     | 大家来找茬小游戏 🔍      |
| `>`    | 左边更强检测   | `100 > 99` ✅    | 体重秤测谁更重 ⚖️        |
| `<`    | 右边更轻检测   | `15 < 20` ✅     | 跷跷板平衡测试 🎢        |
| `>=`   | 不小于检测仪   | `18 >= 18` ✅    | 过山车最低身高线 🎢      |
| `<=`   | 不大于检测仪   | `7 <= 10` ✅     | 儿童票身高限高线 👧      |

## 🧩 逻辑运算符——「条件组合大师」

把多个条件变成连锁机关的「组合魔法」：

| 运算符 | 魔法名称     | 特性         | 现实场景案例                | 真值表速记                  |
|--------|--------------|--------------|-----------------------------|-----------------------------|
| `&&`   | 双重要求门   | 全真才通     | 同时有学生证 && 家长同意 ✅ | 1+1=1，其他0                 |
| `\|\|` | 保底通道     | 任真即可     | 只要有一项满足即可通过      | 0+0=0，其他1                 |
| `!`    | 反转次元门   | 真假反转     | 周末且 !生病才能玩 🎮       | !1=0，!0=1                   |

### 解锁高级条件：
```cpp
int age = 12;
bool hasParent = true;

// 「年龄>=12岁」或者「有家长陪同」
bool canWatchMovie = (age >= 12) || hasParent;  
// 输出：true (满足第二个条件)
```

## 🚦 运算符优先顺序——魔法咒语吟唱规则

优先级越高越先执行，依次排序：
1. 比较运算符家族：`>`, `>=`, `<`, `<=`, `==`, `!=`
2. `!` 反转大师：拥有最高优先级
3. `&&` 严格门卫：比 `\|\|` 优先级高
4. `\|\|` 宽容门卫：垫底执行

### 咒语示例：
```cpp
// 不加括号版：先执行!，再比较运算，最后处理逻辑
bool result1 = 10 > 5 && !3 == 0; 

// 等价加括号版：
bool result2 = (10 > 5) && (!(3 == 0)); 
```

## 🎲 优先级闯关游戏！

判断以下表达式的执行顺序：
```cpp
!age < 18 && hasTicket || parentWithMe
```

### 💡 拆解答案：
1. 先计算 `!age`
2. 再比较 `(!age) < 18`
3. 处理 `&&` 连接 `hasTicket`
4. 最后处理 `\|\|` 连接 `parentWithMe`

### 🧠 医护小贴士：
建议多用括号显式标记顺序，让代码像乐高说明书一样清晰！ 🧱
