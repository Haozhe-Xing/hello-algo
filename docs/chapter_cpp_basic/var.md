# 📦 魔法容器之谜——变量与常量
## 🎒 变量：会变魔术的百宝箱

### 🧪 变量是什么？
就像贴了标签的魔法瓶，你可以：
- 🏷️ **取名字**（变量名）
- 🔄 **装不同的魔法素材**（存储数据）
- 🔍 **随时查看内容**（访问数据）

```cpp
#include <iostream>
using namespace std;

int main() {
    // 🪄 炼制一个"金币魔法罐"
    int piggyBank = 50;  // 初始存款50元
    cout << "存钱罐余额：" << piggyBank << "元" << endl;
    
    // 🛒 买了一套新漫画
    piggyBank = piggyBank - 35;  // 金额会变化！
    cout << "购买后还剩：" << piggyBank << "元 😢" << endl;
    
    return 0;
}
```

### 📜 命名法则
在C++中，变量的命名遵循一定的规则和约定，以确保代码的可读性和一致性。以下是详细的C++变量命名规则及其最佳实践：

### 基本命名规则

1. **字母、数字和下划线**：
    - 变量名只能包含字母（a-z, A-Z）、数字（0-9）和下划线（_）。
    - 变量名不能以数字开头。

2. **区分大小写**：
    - C++是区分大小写的语言，因此`myVar`和`myvar`被视为两个不同的变量。

3. **保留字**：
    - 不能使用C++中的关键字作为变量名，如`int`, `double`, `for`, `if`, `while`, `return`等。

4. **长度限制**：
    - 尽管现代编译器通常支持任意长度的标识符，但根据标准，实现必须至少识别前1024个字符。不过，为保持代码清晰，建议避免过长的变量名。

### 命名约定

尽管C++标准对变量命名没有强制性的风格要求，但为了提高代码的可读性和维护性，开发者们通常遵循以下一些命名约定：

#### 驼峰命名法（Camel Case）
- **小驼峰命名法**：第一个单词首字母小写，后续每个单词首字母大写，不使用下划线分隔。例如：`firstName`, `studentId`。
- **大驼峰命名法（Pascal Case）**：所有单词首字母均大写，不使用下划线分隔。例如：`FirstName`, `StudentId`。这种方法常用于类名或结构体名。

#### 下划线命名法（Snake Case）
- 所有字母均为小写，单词之间用下划线分隔。例如：`first_name`, `student_id`。这种命名方式在C++社区中也很常见，尤其是在变量和函数名中。

#### 其他注意事项
- **有意义的名字**：尽量选择能够反映变量用途的名字。例如，使用`totalScore`而不是`ts`。
- **避免单字母变量名**：除非是在循环计数器或简单的数学公式中（如`i`, `j`, `k`），否则应避免使用单字母变量名。
- **常量命名**：常量名通常全部大写，并用下划线分隔单词。例如：`MAX_SIZE`, `PI`。如果使用`const`或`constexpr`定义，则也可以采用驼峰命名法。

#### 示例
```cpp
// 合法且推荐的变量命名示例
int studentAge;          // 小驼峰命名法
float maximumHeight;     // 小驼峰命名法
std::string first_name;  // 下划线命名法
const int MAX_TRIES = 5; // 全部大写，适用于常量
```


## ⛔ 常量：封印的魔法卷轴

### ⌛ 什么是常量？
像被施了永久固化咒的魔法物品：
- 🔒 **一旦设定无法更改**
- 🔖 **常用于重要数值**（比如圆周率π）

```cpp
#include <iostream>
using namespace std;

int main() {
    // 🧙♂️ 用const声明"被加固的宝物箱"
    const double PI = 3.14159;  // 圆周率之神圣封印
    const int MAX_HP = 100;     // 游戏角色满血值
    
    // ⚔️ 尝试破解封印会失败！
    // MAX_HP = 200;  // 电脑会生气地报错💢
    
    cout << "满血战士的生命值：" << MAX_HP << " ❤️" << endl;
    return 0;
}
```
